# 介绍

Rspack 是一个基于 Rust 编写的高性能 Web 打包工具，它提供现代化的 webpack API，能够无缝替换 webpack，并提供闪电般的构建速度。

## 为什么选择 Rspack \{#why-rspack}

### 更快的开发反馈 \{#faster-development-feedback}

Rspack 最初是为解决大型 JavaScript 应用的构建性能问题而设计的。它使用 Rust 编写，通过并行架构充分利用多核 CPU，并结合[增量编译](/config/incremental)、[按需编译](/guide/advanced/lazy-compilation)和[持久化缓存](/config/cache)来提升构建效率。

这些改进大幅缩短了开发服务器启动、热更新和生产构建的耗时，使 Rspack 相比 webpack 有十倍以上的性能提升。

### 让代码运行更快 \{#make-your-code-run-faster}

Rspack 致力于生成体积更小、运行更快的构建产物。通过 [tree shaking](/guide/optimization/tree-shaking) 和代码压缩等优化能力，它能够帮助你消除产物中的冗余代码，减小资源体积。

Rspack 还提供强大的[代码分割](/guide/optimization/code-splitting)能力，这允许你精细控制模块如何拆分和共享，使 JavaScript 应用达到最佳的加载性能。

### 从开箱即用到自由定制 \{#from-ready-to-use-to-fully-customizable}

Rspack 生态包含了面向不同场景的工具，比如用于应用开发的 [Rsbuild](https://rsbuild.rs)、用于库开发的 [Rslib](https://rslib.rs) 和用于文档站点的 [Rspress](https://rspress.rs)，都能为你提供开箱即用的支持，减少搭建和维护工具链的成本。

当你需要深入定制时，可以通过 Rspack 的配置、插件和 JavaScript API 调整构建流程，或是开发自己的工具。对于微前端、服务端渲染等进阶场景，Rspack 也提供了[模块联邦](/guide/advanced/module-federation)、[多编译器模式](/api/javascript-api/#multicompiler)、[React Server Components](/guide/integrations/rsc) 等能力来支持。

### 兼容 webpack 生态 \{#compatible-with-the-webpack-ecosystem}

Rspack 兼容 webpack 的绝大部分配置和 API，支持复用已有的 loader 和插件。对于已经使用 webpack 的团队，现有的配置经验和自定义插件仍然可以发挥作用。

参考 [webpack 迁移指南](/guide/migration/webpack) 和 [插件兼容性列表](/plugins/community-plugin-compatibility) 了解更多。

## 认识 Rstack \{#meet-rstack}

围绕 Rspack，我们打造了 **Rstack**，一套面向开发者和 AI Agent 的高性能 JavaScript 工具链。它为应用开发、库开发和文档站点搭建等场景提供开箱即用的支持，并将测试、代码检查和构建分析整合到开发流程中，减少工具配置与集成的成本。

| 工具                                | 用途                                           |
| ----------------------------------- | ---------------------------------------------- |
| [Rsbuild](https://rsbuild.rs/zh/)   | 构建工具，提供默认配置、开发服务器和框架集成   |
| [Rslib](https://rslib.rs/zh/)       | 库开发工具，用于构建 JavaScript 库和 UI 组件库 |
| [Rspress](https://rspress.rs/zh/)   | 静态站点生成器，用于创建文档站点等内容网站     |
| [Rstest](https://rstest.rs/)        | 测试框架，提供单元测试和端到端测试能力         |
| [Rslint](https://rslint.rs/)        | 代码检查工具，支持类型感知规则                 |
| [Rsdoctor](https://rsdoctor.rs/zh/) | 构建分析工具，用于分析构建耗时和产物体积       |
| [Rstack CLI](https://rstack.rs/zh/) | 统一命令行工具，内置 Rstack 的各个工具         |

这些工具既可以独立使用，也可以相互配合。你可以从当前需求出发选择合适的工具，再随着项目发展逐步引入其他工具。
