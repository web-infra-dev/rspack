# Solid

## 如何使用 \{#how-to-use}

推荐使用 [Rsbuild](https://rsbuild.rs/zh/) 开发 Solid 应用，它提供开箱即用的 JSX 编译和热更新支持。创建项目请参阅 [Rsbuild - Solid](https://rsbuild.rs/zh/guide/framework/solid)。

## Solid v2

Solid v2 项目可以在 Rsbuild 中使用 `@rsbuild/plugin-solid` v2。该插件默认使用 Solid 的原生 JSX 编译器，无需额外配置 Babel 插件。安装和配置方式请参阅 [Rsbuild - Solid v2 配置](https://rsbuild.rs/zh/plugins/list/plugin-solid#solid-v2)。

## Solid v1

已有的 Solid v1 项目可以使用 `@rsbuild/plugin-solid@1` 搭配 `@rsbuild/plugin-babel`，配置方式请参阅 [Rsbuild - Solid v1 配置](https://rsbuild.rs/zh/plugins/list/plugin-solid#solid-v1)。

### 手动配置 Rspack \{#configure-solid}

如果直接使用 Rspack，以下配置适用于 **Solid v1**，需要使用 `babel-loader`、`babel-preset-solid` 和 `solid-refresh`。完整项目请参阅 [Solid v1 示例](https://github.com/rstackjs/rstack-examples/tree/main/rspack/solid)。

```js title="rspack.config.mjs"
import { defineConfig } from '@rspack/cli';

export default defineConfig({
  entry: {
    main: './src/index.jsx',
  },
  module: {
    rules: [
      {
        test: /\.jsx$/,
        use: [
          {
            loader: 'babel-loader',
            options: {
              presets: ['solid'],
              plugins: ['solid-refresh/babel'],
            },
          },
        ],
      },
    ],
  },
});
```
