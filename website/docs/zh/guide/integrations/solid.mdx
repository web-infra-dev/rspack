# Solid

## 如何使用 \{#how-to-use}

在 Rspack 中使用 Solid 有两种方式：

- **使用 Rsbuild**：Rsbuild 为 Solid 项目预设了 JSX 编译和模块热替换（HMR）。创建项目请参考 [Rsbuild 的 Solid 指南](https://rsbuild.rs/zh/guide/framework/solid)。
- **手动配置 Rspack**：按照下文配置 `solid-loader`，也可以参考完整的 [Rspack + Solid 示例](https://github.com/rstackjs/rstack-examples/tree/main/rspack/solid)。

## 配置 JSX/TSX \{#configure-solid}

要用 Rspack 2 编译 Solid 2 组件，先安装开发依赖 [solid-loader](https://github.com/rstackjs/solid-loader)。

<PackageManagerTabs command="add solid-loader -D" />

使用 `solid-loader` 编译 JSX 和 TSX，并用 [builtin:swc-loader](/guide/builtin-loaders/swc-loader) 移除 TypeScript 类型。

```ts title="rspack.config.ts"
import { defineConfig } from '@rspack/cli';

export default defineConfig({
  resolve: {
    extensions: ['...', '.ts', '.tsx', '.jsx'],
    conditionNames: ['solid', '...'],
  },
  module: {
    rules: [
      {
        test: /\.[cm]?[jt]sx?$/,
        resolve: {
          fullySpecified: false,
        },
        use: [
          {
            loader: 'builtin:swc-loader',
            options: { detectSyntax: 'auto' },
          },
          'solid-loader',
        ],
      },
      {
        descriptionData: { name: /^@solidjs\/web$/ },
        parser: { importDynamic: false },
      },
    ],
  },
});
```

有些组件库通过 `solid` 导出条件提供 JSX 源码。在 [resolve.conditionNames](/config/resolve#resolveconditionnames) 中加入 `'solid'`，Rspack 就能编译这些源码。保留 `'...'` 可以沿用 Rspack 的默认条件。

水合时，`@solidjs/web` 加载模块所用的 URL 在运行时才能确定。仅对这个包将 [parser.importDynamic](/config/module-parser#javascriptimportdynamic) 设为 `false`，让浏览器通过原生 `import()` 加载模块。

如果项目使用 TypeScript，请在 `tsconfig.json` 中将 `jsx` 设为 `"preserve"`，将 `jsxImportSource` 设为 `"@solidjs/web"`。

## 模块热替换 \{#hot-module-replacement}

在开发模式下，如果浏览器构建启用了 HMR，`solid-loader` 会自动开启 Solid Refresh。修改子组件时，父组件的状态会保留。

## Solid v1

Solid 1 项目使用 `babel-loader` 和 `babel-preset-solid` 编译 JSX，并通过 `solid-refresh` 实现热更新。完整的 Rspack 配置见 [Solid v1 示例](https://github.com/rstackjs/rstack-examples/tree/260651fd01e490145e7f75f46689654d79e2bd94/rspack/solid)。如果使用 Rsbuild，请参考 [Rsbuild 的 Solid v1 配置指南](https://rsbuild.rs/zh/plugins/list/plugin-solid#solid-v1)。
