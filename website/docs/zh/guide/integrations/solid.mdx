# Solid

## 如何使用 \{#how-to-use}

[Rsbuild](https://rsbuild.rs/zh/guide/framework/solid) 为 Solid 项目提供了开箱即用的 JSX 编译和模块热替换（HMR）支持。如果直接使用 Rspack，可以按下文配置，也可以从 [Rspack + Solid 示例](https://github.com/rstackjs/rstack-examples/tree/main/rspack/solid) 开始。

## 配置 JSX/TSX \{#configure-solid}

要用 Rspack 2 编译 Solid 2 组件，先安装开发依赖 [solid-loader](https://github.com/rstackjs/solid-loader)。

<PackageManagerTabs command="add solid-loader -D" />

在 `use` 数组中，将 `solid-loader` 放在 [builtin:swc-loader](/guide/builtin-loaders/swc-loader) 后面。Rspack 从右到左执行 loader，因此 Solid 原生编译器会先转换 JSX，再由 SWC 移除代码中的 TypeScript 类型。普通的 JavaScript 和 TypeScript 文件直接由 SWC 处理。

```ts title="rspack.config.ts"
import { defineConfig } from '@rspack/cli';

export default defineConfig({
  resolve: {
    extensions: ['...', '.ts', '.tsx', '.jsx'],
    conditionNames: ['solid', '...'],
  },
  module: {
    rules: [
      {
        test: /\.[cm]?[jt]sx?$/,
        resolve: {
          fullySpecified: false,
        },
        use: [
          {
            loader: 'builtin:swc-loader',
            options: { detectSyntax: 'auto' },
          },
          'solid-loader',
        ],
      },
      {
        descriptionData: { name: /^@solidjs\/web$/ },
        parser: { importDynamic: false },
      },
    ],
  },
});
```

有些组件库在 `package.json` 中通过 `solid` 导出条件提供 JSX 源码。将 `'solid'` 加入 [resolve.conditionNames](/config/resolve#resolveconditionnames)，Rspack 就能用应用的编译配置处理这些源码。`'...'` 表示保留 Rspack 的默认条件，例如浏览器构建中的 `browser` 和开发模式下的 `development`。

水合时，`@solidjs/web` 会通过 `import(url)` 加载模块，具体的 URL 在运行时才能确定。示例中的第二条规则只匹配 `@solidjs/web`。将它的 [parser.importDynamic](/config/module-parser#javascriptimportdynamic) 设为 `false` 后，Rspack 会保留原生的 `import()` 调用，由浏览器直接加载模块。

如果项目使用 TypeScript，请在 `tsconfig.json` 中将 `jsx` 设为 `"preserve"`，将 `jsxImportSource` 设为 `"@solidjs/web"`。

## 模块热替换 \{#hot-module-replacement}

运行 `rspack dev` 启动开发服务器。在开发模式下，如果浏览器构建启用了 HMR，`solid-loader` 就会自动开启 Solid Refresh。修改子组件时，可以直接在浏览器中看到变化，父组件也会保留原有状态。

## Solid v1

Solid 1 项目使用 `babel-loader` 和 `babel-preset-solid` 编译 JSX，并通过 `solid-refresh` 实现热更新。完整的 Rspack 配置见 [Solid v1 示例](https://github.com/rstackjs/rstack-examples/tree/260651fd01e490145e7f75f46689654d79e2bd94/rspack/solid)。如果使用 Rsbuild，请参考 [Rsbuild 的 Solid v1 配置指南](https://rsbuild.rs/zh/plugins/list/plugin-solid#solid-v1)。
