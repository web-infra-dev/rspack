# NodeTemplatePlugin

`NodeTemplatePlugin` 用于配置 Node.js 产物，通常配合子编译器使用。

它会应用 [`'commonjs'` chunk format](/config/output#outputchunkformat)，并为 Node.js 运行时配置 [output.chunkLoading](/config/output#outputchunkloading)。

默认情况下，它会将 `output.chunkLoading` 设为 `'require'`。当启用 `asyncChunkLoading` 时，则会改为 `'async-node'`。

```js
new rspack.node.NodeTemplatePlugin();
```

## 选项

### asyncChunkLoading

- 类型：`boolean`
- 默认值：`false`

使用 `'async-node'` 而不是 `'require'` 加载异步 chunk。

## 示例

下面的 Node.js 入口会将 `task.js` 生成为异步 chunk：

```js title="src/index.js"
async function main() {
  const { run } = await import('./task.js');
  run();
}

main();
```

```js title="rspack.config.mjs"
export default {
  target: 'node',
  entry: './src/index.js',
  output: {
    chunkLoading: 'require',
  },
};
```

Rspack 会生成 CommonJS chunk，并通过 `require` 加载异步 chunk。常规的 `target: 'node'` 构建会自动配置相同的行为。当子编译器需要生成 Node.js 风格的 chunk 时，可以直接应用 `NodeTemplatePlugin`。
