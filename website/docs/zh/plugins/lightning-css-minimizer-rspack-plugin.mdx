# LightningCssMinimizerRspackPlugin

<ApiMeta specific={['Rspack']} />

此插件使用 [lightningcss](https://lightningcss.dev/) 来压缩 CSS 产物。参见 [optimization.minimizer](/config/optimization#optimizationminimizer)。

## 示例

```js title="rspack.config.mjs"
import { rspack } from '@rspack/core';

export default {
  mode: 'production',
  optimization: {
    minimizer: [
      new rspack.SwcJsMinimizerRspackPlugin(),
      new rspack.LightningCssMinimizerRspackPlugin(),
    ],
  },
};
```

设置 `optimization.minimizer` 会替换默认的压缩器。配置 CSS 压缩器时，同时添加 `SwcJsMinimizerRspackPlugin` 可以保留 JavaScript 压缩。

## 选项

### include

- **Type:** `string | RegExp | (string | RegExp)[]`
- **Default:** `undefined`

使用此选项来指定应该被压缩的文件，匹配产物文件的路径。

### exclude

- **Type:** `string | RegExp | (string | RegExp)[]`
- **Default:** `undefined`

使用此选项来指定应该排除在压缩之外的文件，匹配产物文件的路径。

例如，跳过名为 `vendor.css` 的产物，同时继续压缩其他 CSS 产物：

```js
new rspack.LightningCssMinimizerRspackPlugin({
  exclude: /vendor\.css$/,
});
```

这里匹配的是产物文件名，不是 `src/vendor.css` 这样的源文件路径。它与控制 CSS 语法转换的 `minimizerOptions.exclude` 不同。

### test

- **Type:** `string | RegExp | (string | RegExp)[]`
- **Default:** `undefined`

使用此选项设置一个模式来匹配 CSS 文件。如果产物文件的路径能匹配给定模式，它将被压缩，否则将不会被压缩。

### removeUnusedLocalIdents

- **类型：** `boolean`
- **默认值：** `true`

是否自动移除未使用的 CSS Modules 的本地标识符，包括未使用的 CSS 类名、id 和 @keyframe 名称。这些声明将被移除。

比如以下 CSS Modules，导出了类名 a 和类名 b，但只在 js 文件中使用了类名 a：

```css title=index.module.css
.a {
  color: red;
}

.b {
  color: blue;
}
```

```js title=index.js
import * as styles from './index.module.css';
document.body.className = styles.a;
```

此时会通过 Rspack 的 tree shaking 功能获取类名 b 未被使用这一信息，提供给 lightningcss，在 minimize 时会将 CSS 产物中类名 b 的声明一并删除，得到以下最终产物：

{/* prettier-ignore */}
```css
.a{color: red}
```

### minimizerOptions

传给 Lightning CSS 进行压缩的配置。

以下是支持的配置，其中 `targets` 配置为 browserslist 查询字符串，其他配置的详细解释请查看 [lightningcss 文档](https://lightningcss.dev/transpilation.html)

:::info

1. 插件按以下顺序确定 `targets`：
   - 优先使用显式配置的 `minimizerOptions.targets`。
   - 未配置时，继承 Rspack 的 [`target`](/config/target#default-behavior) 提供的目标信息，只保留支持的浏览器。如果目标中不包含支持的浏览器（如 `browserslist:node 18`），则使用空目标。
   - 如果 Rspack 未提供目标信息（如 `web`），则默认使用 `"fully supports es6"`。

   为了减小体积，Lightning CSS 在压缩时可能会改用更短的新语法。这个默认值限定了可以使用的语法范围，让压缩后的代码也能兼容上述浏览器。

2. `minimizerOptions.include` 和 `minimizerOptions.exclude` 默认不强制或排除任何特性。Lightning CSS 根据 `targets` 决定需要执行哪些语法转换。可以使用 `include: { nesting: true }` 这样的特性对象强制转换，也可以使用 `exclude: { nesting: true }` 阻止转换。

我们建议并鼓励用户配置自己所需的 `targets`，以获得最好的压缩效果。
:::

例如，将目标设为 Chrome 100 及更高版本。以下配置使用[内置 CSS 支持](/guide/languages/css#built-in-css-support)，并同时保留 JavaScript 和 CSS 压缩：

```js title="rspack.config.mjs"
import { rspack } from '@rspack/core';

export default {
  mode: 'production',
  devtool: false,
  entry: './src/index.js',
  output: {
    cssFilename: '[name].css',
  },
  module: {
    rules: [{ test: /\.css$/i, type: 'css' }],
  },
  optimization: {
    minimizer: [
      new rspack.SwcJsMinimizerRspackPlugin(),
      new rspack.LightningCssMinimizerRspackPlugin({
        minimizerOptions: {
          targets: ['chrome >= 100'],
        },
      }),
    ],
  },
};
```

```js title="src/index.js"
import './style.css';
console.log('Hello');
```

```css title="src/style.css"
.card {
  color: red;

  &:hover {
    color: blue;
  }
}
```

由于 Chrome 100 不支持 CSS 嵌套语法，压缩器会展开嵌套规则，生成：

{/* prettier-ignore */}
```css title="dist/main.css"
.card{color:red}.card:hover{color:#00f}
```

如果将 `minimizerOptions.exclude` 设置为 `{ nesting: true }`，即使使用上述目标，也会保留嵌套规则，因此产物需要在支持嵌套语法的浏览器中运行。相反，`include: { nesting: true }` 会强制转换嵌套语法，即使所有目标浏览器都支持它。

与插件顶层的 `include` 和 `exclude` 不同，这些特性选项不会筛选文件，而是控制对选中的 CSS 产物执行哪些语法转换。

```ts
  android?: string;
  chrome?: string;
  edge?: string;
  firefox?: string;

  samsung?: string;

type LightningCssMinimizerOptions = {
  errorRecovery?: boolean;
  targets?: string[] | string | Targets;

  exclude?: LightningcssFeatureOptions;
  drafts?: Drafts;

  oklabColors?: boolean;

  spaceSeparatedColorNotation?: boolean;
  fontFamilySystemUi?: boolean;
  doublePositionGradients?: boolean;
  vendorPrefixes?: boolean;

  mediaQueries?: boolean;

```
