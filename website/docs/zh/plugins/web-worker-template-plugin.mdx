# WebWorkerTemplatePlugin

`WebWorkerTemplatePlugin` 用于配置 Web Worker 产物，通常配合子编译器使用。

它会将 [output.chunkLoading](/config/output#outputchunkloading) 设为 `'import-scripts'`，并应用 web worker 目标使用的 [`'array-push'` chunk format](/config/output#outputchunkformat)。

```js
new rspack.webworker.WebWorkerTemplatePlugin();
```

## 示例

下面的 worker 会先将 `math.js` 作为异步 chunk 加载，再处理收到的消息：

```js title="src/worker-child.js"
self.onmessage = async ({ data }) => {
  const { double } = await import('./math.js');
  self.postMessage(double(data));
};
```

```js title="src/math.js"
export const double = (value) => value * 2;
```

下面的配置会创建一个子编译器，并直接对它应用 `WebWorkerTemplatePlugin`：

```js title="rspack.config.mjs"
export default {
  target: 'webworker',
  entry: {},
  plugins: [
    (compiler) => {
      compiler.hooks.make.tapAsync(
        'WorkerChildCompiler',
        (compilation, callback) => {
          const childCompiler = compilation.createChildCompiler(
            'worker-child',
            {
              filename: 'worker-child.js',
              chunkFilename: '[name].worker-child.js',
            },
            [
              new compiler.rspack.webworker.WebWorkerTemplatePlugin(),
              new compiler.rspack.EntryPlugin(
                compiler.context,
                './src/worker-child.js',
                { name: 'worker-child' },
              ),
            ],
          );

          childCompiler.runAsChild((error) => callback(error));
        },
      );
    },
  ],
};
```

`WebWorkerTemplatePlugin` 会让子编译器生成 array-push chunk，并通过 `importScripts` 加载其中的异步 chunk。

对于常规 Web Worker 构建，请改用 `target: 'webworker'`。它会自动选择 `'array-push'` chunk format 和 `'import-scripts'` chunk loading。设置 `output.chunkLoading: 'import-scripts'` 只会选择 chunk 加载实现，并不会应用 `WebWorkerTemplatePlugin`。
