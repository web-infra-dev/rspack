# ElectronTargetPlugin

`ElectronTargetPlugin` 会将 Electron 内置模块保留为外部依赖，使其在运行时由 Electron 加载，而不是被 Rspack 打进产物。[`externalsPresets.electron`](/config/externals#externalspresetselectron)、[`externalsPresets.electronMain`](/config/externals#externalspresetselectronmain)、[`externalsPresets.electronRenderer`](/config/externals#externalspresetselectronrenderer) 和 [`externalsPresets.electronPreload`](/config/externals#externalspresetselectronpreload) 的底层使用了该插件。

直接应用插件时，可以传入 `'main'`、`'preload'` 或 `'renderer'`，以外置对应 Electron 进程中可用的其他内置模块。

```js
new rspack.electron.ElectronTargetPlugin('main');
```

## 示例

对于常规 Electron 应用，设置合适的 [target](/config/target) 是启用此插件最简单的方式。下面的主进程构建会在生成的 bundle 中保留 `electron` 导入，并在运行时由 Electron 提供：

```js title="rspack.config.mjs"
export default {
  target: 'electron-main',
  entry: './src/main.js',
};
```

```js title="src/main.js"
import { app, BrowserWindow } from 'electron';

app.whenReady().then(() => {
  new BrowserWindow();
});
```

`target: 'electron-main'` 会启用 Electron 主进程的 externals preset，并在内部以 `'main'` 上下文应用 `ElectronTargetPlugin`。直接应用插件主要用于配置子编译器。
