# ExternalsPlugin

允许你指定外部依赖项，这些依赖项将不打包到输出文件中。这对于已经在全局范围内可用或通过其他方式另外管理的库非常有用。
[`externalsType`](/config/externals#externalstype) 和 [`externals`](/config/externals#externals) 配置内部使用了该插件实现，你可以直接通过配置项来使用相应的功能，而无需单独使用插件。

## 示例

将 React 作为 CommonJS 依赖排除在打包产物之外：

```js title="rspack.config.mjs"
import { rspack } from '@rspack/core';

export default {
  plugins: [new rspack.ExternalsPlugin('commonjs', ['react'])],
};
```

## 选项

### type

**类型：**

```ts
type ExternalsType =
  | 'var'
  | 'module'
  | 'assign'
  | 'this'
  | 'window'
  | 'self'
  | 'global'
  | 'commonjs'
  | 'commonjs2'
  | 'commonjs-module'
  | 'commonjs-static'
  | 'amd'
  | 'amd-require'
  | 'umd'
  | 'umd2'
  | 'jsonp'
  | 'system'
  | 'promise'
  | 'import'
  | 'module-import'
  | 'modern-module'
  | 'commonjs-import'
  | 'script'
  | 'node-commonjs';
```

指定 `externals` 的默认类型。

详细信息请参阅 [externalsType](/config/externals#externalstype)。

### externals

**类型：**

```ts
type Externals = ExternalItem[] | ExternalItem;

type ExternalItem =
  | string
  | RegExp
  | ExternalItemObjectUnknown
  | ((
      data: ExternalItemFunctionData,
      callback: (
        err?: Error | null,
        result?: ExternalItemValue,
        type?: ExternalsType,
      ) => void,
    ) => ExternalItemValue | void | Promise<ExternalItemValue | void>);

type ExternalItemObjectUnknown = {
  [request: string]: ExternalItemValue;
};

type ExternalItemValue =
  | string[]
  | boolean
  | string
  | {
      [k: string]: any;
    };

type ExternalItemFunctionData = {
  context?: string;
  contextInfo?: ModuleFactoryCreateDataContextInfo;
  getResolve?: (
    options?: ResolveOptions,
  ) => ((context: string, request: string, callback: ResolveCallback) => void) &
    ((context: string, request: string) => Promise<string | undefined>);
  request?: string;
};

type ResolveCallback = (
  err: (Error & { details?: string }) | null,
  result?: string | false,
  resolveData?: ResolveRequest,
) => void;

type ModuleFactoryCreateDataContextInfo = {
  issuer: string;
  compiler: string;
};
```

`getResolve()` 返回的解析函数同时支持 `resolve(context, request, callback)` 和 `await resolve(context, request)`。对于被忽略的请求，回调收到的解析结果为 `false`，Promise 的结果为 `undefined`。回调的第三个参数还可提供解析详情，其中 `descriptionFileData` 是解析后的包描述文件内容。

**阻止**将某些 import 的包（package）打包到 bundle 中，而是在运行时（runtime）再去从外部获取这些*扩展依赖*（external dependencies）。

详细信息请参阅 [externals](/config/externals#externals)。
