# CompactChunkIdsPlugin

`CompactChunkIdsPlugin` 根据 Chunk 内容分配稳定的字母数字 id。首字符使用 `a-zA-Z`，后续字符使用 `a-zA-Z0-9`。它会从配置的最短 hash 前缀开始，并在该前缀已被使用时延长 id。

`optimization.chunkIds: 'compact'` 内部会使用该插件。只有在需要自定义 compact id 生成行为时，才需要直接使用该插件。

```js title="rspack.config.mjs"
import rspack from '@rspack/core';

export default {
  plugins: [
    new rspack.ids.CompactChunkIdsPlugin({
      minLength: 1,
    }),
  ],
};
```

## 选项

### minLength

- **类型：** `number`
- **默认值：** `1`

编码后 id 的最小长度。如果 hash 前缀已经被使用，Rspack 会逐个字符延长该 id。如果完整 hash 仍然冲突，编译会失败并报告错误。
