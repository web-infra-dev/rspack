# JsonpTemplatePlugin

`JsonpTemplatePlugin` configures browser assets and is most often used with a child compiler.

It sets [output.chunkLoading](/config/output#outputchunkloading) to `'jsonp'` and applies the [`'array-push'` chunk format](/config/output#outputchunkformat) used by web targets.

```js
new rspack.web.JsonpTemplatePlugin();
```

## Example

The following browser entry creates an asynchronous chunk for `message.js`:

```js title="src/browser-child.js"
document.querySelector('button').addEventListener('click', async () => {
  const { message } = await import('./message.js');
  console.log(message);
});
```

```js title="src/message.js"
export const message = 'Hello from the child compiler';
```

This configuration creates a child compiler and applies `JsonpTemplatePlugin`
directly to it:

```js title="rspack.config.mjs"
export default {
  target: 'web',
  entry: {},
  plugins: [
    (compiler) => {
      compiler.hooks.make.tapAsync(
        'BrowserChildCompiler',
        (compilation, callback) => {
          const childCompiler = compilation.createChildCompiler(
            'browser-child',
            {
              filename: 'browser-child.js',
              chunkFilename: '[name].browser-child.js',
            },
            [
              new compiler.rspack.web.JsonpTemplatePlugin(),
              new compiler.rspack.EntryPlugin(
                compiler.context,
                './src/browser-child.js',
                { name: 'browser-child' },
              ),
            ],
          );

          childCompiler.runAsChild((error) => callback(error));
        },
      );
    },
  ],
};
```

`JsonpTemplatePlugin` configures the child compiler to emit array-push chunks and
load the asynchronous chunk by adding a script to the page.

For a regular web build, use `target: 'web'` instead. It selects the
`'array-push'` chunk format and `'jsonp'` chunk loading automatically. Setting
`output.chunkLoading: 'jsonp'` selects the chunk-loading implementation, but it
does not apply `JsonpTemplatePlugin`.
