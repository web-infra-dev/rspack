# JsonpTemplatePlugin

`JsonpTemplatePlugin` configures browser assets and is most often used with a child compiler.

It sets [output.chunkLoading](/config/output#outputchunkloading) to `'jsonp'` and applies the [`'array-push'` chunk format](/config/output#outputchunkformat) used by web targets.

```js
new rspack.web.JsonpTemplatePlugin();
```

## Example

This browser entry creates an asynchronous chunk for `message.js`:

```js title="src/index.js"
document.querySelector('button').addEventListener('click', async () => {
  const { message } = await import('./message.js');
  console.log(message);
});
```

```js title="rspack.config.mjs"
export default {
  target: 'web',
  entry: './src/index.js',
  output: {
    chunkLoading: 'jsonp',
  },
};
```

When the button is clicked, Rspack loads the asynchronous chunk by adding a script to the page. For a normal web build, `target: 'web'` and `output.chunkLoading: 'jsonp'` enable the same behavior automatically. Apply `JsonpTemplatePlugin` directly when a child compiler needs browser-style chunk output.
