# WebWorkerTemplatePlugin

`WebWorkerTemplatePlugin` configures Web Worker assets and is most often used with a child compiler.

It sets [output.chunkLoading](/config/output#outputchunkloading) to `'import-scripts'` and applies the [`'array-push'` chunk format](/config/output#outputchunkformat) used by web worker targets.

```js
new rspack.webworker.WebWorkerTemplatePlugin();
```

## Example

The following worker loads `math.js` as an asynchronous chunk before processing a message:

```js title="src/worker-child.js"
self.onmessage = async ({ data }) => {
  const { double } = await import('./math.js');
  self.postMessage(double(data));
};
```

```js title="src/math.js"
export const double = (value) => value * 2;
```

This configuration creates a child compiler and applies `WebWorkerTemplatePlugin` directly to it:

```js title="rspack.config.mjs"
export default {
  target: 'webworker',
  entry: {},
  plugins: [
    (compiler) => {
      compiler.hooks.make.tapAsync(
        'WorkerChildCompiler',
        (compilation, callback) => {
          const childCompiler = compilation.createChildCompiler(
            'worker-child',
            {
              filename: 'worker-child.js',
              chunkFilename: '[name].worker-child.js',
            },
            [
              new compiler.rspack.webworker.WebWorkerTemplatePlugin(),
              new compiler.rspack.EntryPlugin(
                compiler.context,
                './src/worker-child.js',
                { name: 'worker-child' },
              ),
            ],
          );

          childCompiler.runAsChild((error) => callback(error));
        },
      );
    },
  ],
};
```

`WebWorkerTemplatePlugin` configures the child compiler to emit array-push chunks and load its asynchronous chunk with `importScripts`.

For a regular Web Worker build, use `target: 'webworker'` instead. It selects the `'array-push'` chunk format and `'import-scripts'` chunk loading automatically. Setting `output.chunkLoading: 'import-scripts'` selects the chunk-loading implementation, but it does not apply `WebWorkerTemplatePlugin`.
