# NodeTemplatePlugin

`NodeTemplatePlugin` configures Node.js assets and is most often used with a child compiler.

It applies the [`'commonjs'` chunk format](/config/output#outputchunkformat) and configures [output.chunkLoading](/config/output#outputchunkloading) for Node.js runtimes.

By default it sets `output.chunkLoading` to `'require'`. When `asyncChunkLoading` is enabled, it uses `'async-node'` instead.

```js
new rspack.node.NodeTemplatePlugin();
```

## Options

### asyncChunkLoading

- Type: `boolean`
- Default: `false`

Use `'async-node'` chunk loading for async chunks instead of `'require'`.

## Example

The following Node.js entry creates an asynchronous chunk for `task.js`:

```js title="src/node-child.js"
async function main() {
  const { run } = await import('./task.js');
  run();
}

main();
```

```js title="src/task.js"
export function run() {
  console.log('Task completed');
}
```

This configuration creates a child compiler and applies `NodeTemplatePlugin` directly to it:

```js title="rspack.config.mjs"
export default {
  target: 'node',
  entry: {},
  plugins: [
    (compiler) => {
      compiler.hooks.make.tapAsync(
        'NodeChildCompiler',
        (compilation, callback) => {
          const childCompiler = compilation.createChildCompiler(
            'node-child',
            {
              filename: 'node-child.js',
              chunkFilename: '[name].node-child.js',
            },
            [
              new compiler.rspack.node.NodeTemplatePlugin(),
              new compiler.rspack.EntryPlugin(
                compiler.context,
                './src/node-child.js',
                { name: 'node-child' },
              ),
            ],
          );

          childCompiler.runAsChild((error) => callback(error));
        },
      );
    },
  ],
};
```

`NodeTemplatePlugin` configures the child compiler to emit CommonJS chunks and load its asynchronous chunk with `require`.

For a regular Node.js build, use `target: 'node'` instead. It selects the `'commonjs'` chunk format and `'require'` chunk loading automatically. Setting `output.chunkLoading: 'require'` selects the chunk-loading implementation, but it does not apply `NodeTemplatePlugin`.
