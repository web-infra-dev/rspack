# Solid

## How to use

We recommend [Rsbuild](https://rsbuild.rs/) for Solid applications. It provides JSX compilation and hot module replacement out of the box. See [Rsbuild - Solid](https://rsbuild.rs/guide/framework/solid) to create a project.

## Solid v2

For Solid v2, use `@rsbuild/plugin-solid` v2 with Rsbuild. The plugin uses Solid's native JSX compiler by default, so no additional Babel plugin is needed. See [Rsbuild - Solid v2 setup](https://rsbuild.rs/plugins/list/plugin-solid#solid-v2) for installation and configuration.

## Solid v1

For existing Solid v1 projects, use `@rsbuild/plugin-solid@1` with `@rsbuild/plugin-babel`. See [Rsbuild - Solid v1 setup](https://rsbuild.rs/plugins/list/plugin-solid#solid-v1) for configuration.

### Configure Rspack manually \{#configure-solid}

If you use Rspack directly, the following configuration is for **Solid v1**. It uses `babel-loader`, `babel-preset-solid`, and `solid-refresh`.

```js title="rspack.config.mjs"
import { defineConfig } from '@rspack/cli';

export default defineConfig({
  entry: {
    main: './src/index.jsx',
  },
  module: {
    rules: [
      {
        test: /\.jsx$/,
        use: [
          {
            loader: 'babel-loader',
            options: {
              presets: ['solid'],
              plugins: ['solid-refresh/babel'],
            },
          },
        ],
      },
    ],
  },
});
```
