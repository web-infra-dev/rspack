# Solid

## How to use

There are two ways to use Solid with Rspack:

- **Use Rsbuild**: Rsbuild configures JSX compilation and hot module replacement (HMR) for Solid projects. To create a project, follow the [Rsbuild guide for Solid](https://rsbuild.rs/guide/framework/solid).
- **Configure Rspack manually**: Follow this guide to set up `solid-loader`, or start from the [Rspack + Solid example](https://github.com/rstackjs/rstack-examples/tree/main/rspack/solid).

## Configure JSX/TSX \{#configure-solid}

To compile Solid 2 components with Rspack 2, install [solid-loader](https://github.com/rstackjs/solid-loader) as a development dependency.

<PackageManagerTabs command="add solid-loader -D" />

Use `solid-loader` to compile JSX and TSX and [builtin:swc-loader](/guide/builtin-loaders/swc-loader) to strip TypeScript types.

```ts title="rspack.config.ts"
import { defineConfig } from '@rspack/cli';

export default defineConfig({
  resolve: {
    extensions: ['...', '.ts', '.tsx', '.jsx'],
    conditionNames: ['solid', '...'],
  },
  module: {
    rules: [
      {
        test: /\.[cm]?[jt]sx?$/,
        resolve: {
          fullySpecified: false,
        },
        use: [
          {
            loader: 'builtin:swc-loader',
            options: { detectSyntax: 'auto' },
          },
          'solid-loader',
        ],
      },
      {
        descriptionData: { name: /^@solidjs\/web$/ },
        parser: { importDynamic: false },
      },
    ],
  },
});
```

Add `'solid'` to [resolve.conditionNames](/config/resolve#resolveconditionnames) so Rspack can compile JSX source from libraries that expose it under the `solid` export condition. Keep `'...'` to include Rspack's default conditions.

During hydration, `@solidjs/web` imports modules from URLs that are only known at runtime. Set [parser.importDynamic](/config/module-parser#javascriptimportdynamic) to `false` for this package so the browser can load those modules with native `import()`.

For TypeScript projects, set `jsx` to `"preserve"` and `jsxImportSource` to `"@solidjs/web"` in `tsconfig.json`.

## Hot module replacement

In development mode, `solid-loader` enables Solid Refresh automatically for browser builds with HMR enabled. Editing a child component then preserves its parent's state.

## Solid v1

Solid 1 projects use `babel-loader` with `babel-preset-solid` to compile JSX and `solid-refresh` for hot updates. See the [Solid v1 example](https://github.com/rstackjs/rstack-examples/tree/260651fd01e490145e7f75f46689654d79e2bd94/rspack/solid) for the full Rspack configuration, or follow the [Rsbuild guide for Solid v1](https://rsbuild.rs/plugins/list/plugin-solid#solid-v1).
