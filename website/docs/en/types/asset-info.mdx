For descriptions of common asset metadata fields, see [Asset info](/api/javascript-api/stats-json#asset-info).

`mode` specifies the Unix permissions applied when writing the asset. `timestamps` specifies its access and modification times in nonnegative milliseconds since the Unix epoch. CopyRspackPlugin populates these fields when the corresponding preservation options are enabled. A plugin can pass the asset's `info` to `emitAsset` to keep these attributes when emitting it again.

When re-emitting an asset with the same name and content, omitted file attributes keep their previous values. Pass `undefined` for `mode` or `timestamps` to clear that attribute. With an `updateAsset` info callback, its return value determines the file attributes.

```ts
type AssetInfo = {
  immutable?: boolean;
  minimized?: boolean;
  fullhash?: string | Array<string>;
  chunkhash?: string | Array<string>;
  contenthash?: string | Array<string>;
  sourceFilename?: string;
  copied?: boolean;
  mode?: number | undefined;
  timestamps?: { atime: number; mtime: number } | undefined;
  development?: boolean;
  hotModuleReplacement?: boolean;
  javascriptModule?: boolean;
  related?: AssetInfoRelated;
  cssUnusedIdents?: Array<string>;
  isOverSizeLimit?: boolean;
  assetType?: string;
} & Record<string, any>;
```
